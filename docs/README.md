# Nos Arc 기획 문서

Nos Arc는 일본 만화 파일을 개인 서버에 보관하고, 작품·장르·화 단위로 정리해 웹에서 읽는 일본 만화 번역 아카이브다. 사이트 전체는 하나의 공유 비밀번호로 보호하며, 업로드할 때 번역을 선택하면 OCR과 번역을 백그라운드 작업으로 처리한다.

## 핵심 결정

- 사이트 진입 전에는 비밀번호 화면만 보여 준다. 정상 상태의 화면 구성은 `assets/uma.gif`와 비밀번호 입력창이다.
- 입력창은 Enter로 제출한다. 별도 로그인 ID와 회원가입은 MVP 범위에 넣지 않는다.
- 비밀번호는 저장소에 넣지 않고 `.env`에서 주입한다. 운영 환경에서는 평문보다 Argon2id 해시를 우선한다.
- 원본 파일은 항상 보존하고, 페이지 이미지와 OCR·번역 결과는 원본에서 파생된 데이터로 관리한다.
- 업로드 요청은 즉시 반환한다. PDF 변환, 압축 해제, OCR, 번역, 렌더링은 작업 큐에서 처리한다.
- N100 16GB 미니 PC를 기준으로 AI 작업 동시성은 기본 1개로 제한하고, 모델은 작업 단계별로 분리해 필요할 때만 메모리에 올린다.
- 기본 번역은 로컬 실행을 우선한다. 외부 API는 별도 어댑터로 추가할 수 있으나 기본값으로 사용하지 않는다.

## 주요 화면

1. 비밀번호 화면: `assets/uma.gif`와 입력창만 표시한다. 프로젝트의 브라우저 제목은 `Nos Arc`로 설정한다.
2. 서재: 만화 이름, 표지, 장르 태그, 번역 상태를 카드로 표시한다.
3. 만화 상세: 작품 정보와 화 목록을 표시하고, 관리자용 업로드 폼에서 화 번호와 파일을 받는다.
4. 리더: 원본 페이지를 기본으로 보여 주며 번역 데이터가 있으면 말풍선 위치에 번역 오버레이를 표시한다.
5. 작업 상태: 업로드 후 별도 화면에 머무르지 않아도 되도록 전역 작업 패널에서 진행률과 오류를 확인한다.

## 자산 경로

현재 저장소의 움짤 원본은 `assets/uma.gif`다. 구현 시 정적 자산 URL을 `/assets/uma.gif`로 고정하고, Windows 경로 구분자를 URL에 직접 사용하지 않는다. 배포 전 정적 파일 존재 여부를 검사해 비밀번호 화면에서 깨진 이미지가 나오지 않게 한다. 화면 요구사항상 파일이 없을 때 임의의 대체 이미지를 노출하지 않고 배포 검사를 실패시키는 편이 맞다.

## MVP에서 제외하는 것

- 공개 회원가입, 여러 사용자 계정, 소셜 로그인
- 원본 이미지를 덮어쓰는 번역본 생성
- 클라우드 저장소 의존
- 모든 언어의 품질을 보장하는 범용 번역
- 저작권이 확인되지 않은 작품의 공개 배포 기능
