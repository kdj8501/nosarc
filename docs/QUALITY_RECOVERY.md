# 8B 역식 품질 개선 기록

## 범위와 확인 방법

- 날짜: 2026-10-01
- 모델: 로컬 Ollama `qwen3:8b`, 추가 추론 비활성화
- 대상: 보관된 1페이지, OCR 영역 22개
- 특정 작품의 인명·단어를 용어집에 추가하지 않았다.
- 한국어·일본어·영어 페르소나, 범용 번역 예시, 구조화 출력과 일반 번역문 출력, 후속 표현 교정을 실제 모델 출력으로 비교했다.
- 원본 DB를 백업하고 DB·미디어 복사본의 별도 서버에서 OCR → 번역 → LaMa → 식자를 두 번 실행했다. 실행 중인 기존 서버의 종료 명령은 자동 실행 검토에서 `blocked by policy`로 거부됐다.
- 마지막 전체 처리 결과는 번역 21개, 누락 1개였다. 누락 영역의 원문은 유지됐다.
- JavaScript 문법 검사, Python 구문 검사, 변경 형식 검사를 수행했다. 자동 단위 테스트는 실행하지 않았다.

## 변경

1. 한국어 단일 문장 번역에서는 번역문만 생성한다. JSON 작성과 유형 분류를 동시에 요구하는 부담을 줄였다. 묶음 요청과 형식 복구는 구조화 출력을 유지한다.
2. 쌍언어 번역가 역할에 조건·부정·가능성·대조·일반 명사·호칭 예시를 제공한다. 예시에는 작품 고유 용어가 없다.
3. 문맥은 용어집과 지시어의 참조 해결에 필요할 때 제공한다. 일반 문장의 첫 번역에 이웃 문장을 무조건 붙이지 않는다.
4. 명백한 부정 누락과 일부 미완성 조건절 오류를 검사하고 의심 문장만 한 번 재요청한다. 미완성 조건절 뒤에 만들어 낸 결론은 제거한다. 이는 완전한 의미 검증이 아니다.
5. 빈 문자열을 정상 한국어로 판단하던 버그를 수정했다. 일본어·영어가 남은 번역의 한국어 재요청이 실제로 실행된다.
6. 후속 한국어 표현 교정은 기본으로 끈다. 비교 중 정확한 초안의 의미를 바꾸는 출력이 확인됐다. `AI_TRANSLATION_OLLAMA_POLISH=true`로 선택할 수 있다.
7. 긴 세로 OCR 입력의 높이 비례 여백을 제한한다. 세로열은 글자 사이 빈 곳에서 나누고 오른쪽부터 읽는다. 주변 그림이 OCR 입력에 들어가는 문제를 줄였다.
8. 원문 제거 여백을 제한하고 신뢰할 수 있는 말풍선 내부에 맞춘다. 원본의 밝은 배경과 주변 여백으로 흰 종이 영역을 판단해 LaMa 복원 뒤 OCR 영역과 글자 윤곽을 정리한다.
9. 번역·렌더링 버전과 교정 설정을 캐시에 반영한다.

## 남은 문제

- 인명 읽기와 표기가 틀리고, 같은 이름의 번역도 일관되지 않는다. 후리가나 정보가 번역 입력에 충분히 보존되지 않는다.
- 일부 일반 단어, 외래어, 말더듬과 시제의 번역이 부자연스럽다.
- 긴 설명문 번역에서 원문에 없는 사실이 추가되는 출력도 남았다.
- 부정·조건 검사는 위 오류를 모두 탐지하지 못한다. 범용 예시가 있는 같은 모델의 자기 검수가 독립적인 정확성 보장은 아니다.
- 번역 누락 1개와 일부 후리가나 잔상이 남았다. 좁은 설명 영역은 작은 세로 글씨로 식자된다.
- 흰 배경 판단은 휴리스틱이다. 다른 작품의 배경·테두리 보호와 인명·문맥 정확성은 추가 페이지 비교가 필요하다.
- 이번 결과는 한 페이지의 정성 비교다. 다른 작품 전체의 품질 향상률이나 N100 처리 성능을 측정한 결과가 아니다.

## 적용

기존 서버를 재시작한 뒤 `역식 다시 실행`으로 새 OCR부터 처리해야 한다. 번역만 재실행하면 기존 OCR 오인식은 그대로 입력된다. 8B 모델 설정은 유지한다.
